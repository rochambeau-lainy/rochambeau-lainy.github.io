# Mémorial de Rochambeau Lainy

Site mémorial consacré à Rochambeau Lainy (25 octobre 1968 – 19 août 2026), enseignant-chercheur, linguiste et acteur du développement des savoirs en Haïti.

Le site est une page statique compatible avec GitHub Pages. Il ne nécessite ni base de données ni serveur d’application.

## Publication

La publication est automatisée par le workflow GitHub Pages placé dans `.github/workflows/pages.yml`.
